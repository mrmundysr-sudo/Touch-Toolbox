# Measure Mark (1.4)

Tap **Measure Mark**, then tap the canvas. The crossing of the X is its center. The dialog assigns a permanent number and lets you enter a name plus normalized X, Y, width, and height (0 to 1). Save or Skip name. Tap an existing X in Measure Mark mode to edit it. Move mode can drag it; the X/Y values update from its canvas position. Select an X and use Edit Mark to reopen its details. Copy mark copies one record; Copy Marks copies all marks, ordered by number, with four decimal places and orientation. Values are relative to the imported image or project canvas and are unchanged by pan, zoom, or toolbar visibility. Deleting a mark does not reuse its number. Local project storage retains marks.

The APK requires Android SDK 34 and Gradle 8.9 to build: `./gradlew assembleDebug`. The resulting file is `app/build/outputs/apk/debug/app-debug.apk`.
